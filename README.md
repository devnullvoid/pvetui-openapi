# pvetui-openapi

Interactive Proxmox VE API documentation, generated by [pvetui](https://github.com/devnullvoid/pvetui).

## Browse the API

👉 **[Open API Browser](https://devnullvoid.github.io/pvetui-openapi/)** (Redoc)

Or point any OpenAPI viewer at the raw spec:

```
https://raw.githubusercontent.com/devnullvoid/pvetui-openapi/main/pve-openapi.yaml
```

## About

The spec (`pve-openapi.yaml`) is generated from Proxmox VE's official `apidoc.js`
using the generator in [pvetui](https://github.com/devnullvoid/pvetui). It is
automatically updated on each pvetui release.
